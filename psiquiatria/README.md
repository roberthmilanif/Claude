# Psychiatry OS

Aplicativo web local-first para apoio estruturado à consulta psiquiátrica.

## O que já existe
- roteiro de entrevista em modo teleprompter
- exame do estado mental
- PHQ-9, GAD-7, AUDIT-C e triagem bipolar simplificada
- avaliação estruturada de segurança
- formulação diagnóstica e 5 Ps
- biblioteca prática de psicofármacos com alertas
- plano terapêutico e monitorização
- geração de evolução para prontuário
- salvamento local no navegador e layout responsivo

## Uso
Abra `index.html` ou sirva a pasta como site estático. Dados da consulta ficam no localStorage do dispositivo.

## Segurança clínica
Ferramenta de apoio para profissional habilitado. Diagnóstico e prescrição exigem julgamento clínico, revisão de bula/protocolo local, comorbidades, interações, função renal/hepática e contexto reprodutivo.
