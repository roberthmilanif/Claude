4. CAUSAS POSSIVEIS, POR ORDEM DE PROBABILIDADE, E COMO CADA UMA APARECE NO SCRIPT
========================================================================
A) Pausa intencional (entradaConfirmada = false)
   Script: "entradaConfirmada = false", gateway e canal OK. Nada caiu.

B) Teste feito com numero "reservado" ou ja atendido
   Mudo por desenho, mesmo com a automacao ligada:
   - seus proprios numeros e o numero da recepcao sao tratados como reservados, nao como paciente;
   - numero que ja conversou (ex.: em 13/10) fica com o consultorio e nao reabre sozinho;
   - so a frase EXATA da bio inicia atendimento novo:
       "Ola, vim pelo Nexus e gostaria de falar com o Dr. Roberth."

C) Mac mini dormindo, ou reiniciado sem o servico subir
   Script: "NENHUM job ai.openclaw.*", porta 19789 sem ninguem escutando, "ultimo boot" recente,
   pmset com sleep diferente de 0.

D) WhatsApp da recepcao desvinculado (precisa ler QR de novo)
   Script: channels status com "not linked"; log com loggedOut ou reconnect em loop.

E) Os dois gateways brigando (porta ou credencial)
   Script: EADDRINUSE no log; perfil pessoal com channels.whatsapp.enabled = true (nao deveria).

F) Plugin nao carregou (pasta movida, guard de seguranca falhou)
   Script: "FALTA ~/Documents/nexus-consultorio/..." ou doctor apontando o plugin.

  Copie diag-openclaw-recepcao.sh para o Mac mini e, no Terminal:

  Mande-me o diag-recepcao.txt. Com ele eu fecho a causa em uma resposta.

PASSO 2 - Decidir o que quer da recepcao
  Opcao A: MANTER PAUSADA (estado atual). Atendimento manual pelo WhatsApp da recepcao. Nada a fazer.

  Opcao B: RELIGAR a automacao com as correcoes de 13/10.
     Antes, o que o README do modulo condiciona: liberar so apos teste controlado com NUMERO
     EXTERNO (nao o seu). Limitacoes ainda abertas: audio sem transcricao interrompe o fluxo;
     imagem com legenda pode passar por texto; o modulo nao percebe quando o senhor respondeu
     manualmente na mesma conversa. Aceitando isso, os comandos no Terminal do Mac mini sao:

      openclaw --profile nexus-recepcao config get plugins.entries.nexus-recepcao.config.entradaConfirmada
      openclaw --profile nexus-recepcao config set plugins.entries.nexus-recepcao.config.entradaConfirmada true --strict-json --dry-run
      openclaw --profile nexus-recepcao config set plugins.entries.nexus-recepcao.config.entradaConfirmada true --strict-json
      openclaw --profile nexus-recepcao config validate
      openclaw --profile nexus-recepcao gateway restart
      openclaw --profile nexus-recepcao channels status --probe

     Teste: de um celular que NUNCA falou com a recepcao, mandar a frase exata da bio.
     Esperado em segundos:
       "Ola! Sou o assistente virtual do consultorio do Dr. Roberth Milani. Como posso ajudar?"
     Ao fim do fluxo, UM aviso no seu WhatsApp (nome, contato, categoria; sem relato clinico).
     Reverter: o mesmo "config set ... false" seguido de "gateway restart".
     NAO rodar "openclaw doctor --fix": o README avisa que ele pode criar defaults e ampliar o perfil.

PASSO 3 - Se o script mostrar queda real
  Servico parado:         openclaw --profile nexus-recepcao gateway restart
                          (se o plist sumiu: openclaw --profile nexus-recepcao gateway install --port 19789)

  Porta ocupada:          descobrir quem esta na 19789 (lsof -nP -iTCP:19789) antes de reiniciar.
